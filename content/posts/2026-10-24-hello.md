欢迎来到我的博客！🎉

这是一个用 **Hugo** + **GitHub Pages** 搭建的静态博客。

## 它能做什么
- 用 Markdown 写作，专注内容
- 推送到 GitHub 后自动构建并部署
- 免费、稳定，自带 HTTPS 与 RSS

## 下一步
试着在 **MarkText** 里编辑这篇文章，保存后运行：

```bash
./sync.sh "更新第一篇博客"
```

稍候一两分钟，刷新页面就能看到变化。
